4 Getting started

Export & verify

The profile is the contract. The gate proves the break survived.

What the writer exports

  • Docx — MarkBreak profile through Pandoc + markbreak.lua. Roles become Divs; //break / //break page stay hard breaks.
  • HTML — Same filter; breaks emit break-before CSS. Standalone HTML for review, not the print SoT.
  • ICML — InDesign/InCopy markup for Place into a template. Roles become ParagraphStyle/{role}; breaks are hard Br types. Packaged IDML is later.
  • Print-proof PDF — The Pages view at book trim (File → Export as PDF). This is the product PDF.
  • Pandoc PDF — Secondary path via Convert with Pandoc; labelled as such in the app.

CLI

bash dialect/export.sh --input manuscript.md --format docx
bash dialect/export.sh --input manuscript.md --format html
bash dialect/export.sh --input manuscript.md --format icml
bash dialect/export.sh --input manuscript.md --format pdf --rig book.rig.json

Verify

On the open profile (pinned submodule), the check fails when Word has no real page break: 

bash dialect/markbreak/tools/verify.sh

Prefer fixtures over folklore. See markbreak.com and Specification (0.5.1).

Where layout lives

meta.md holds the publication record. layout points at the RigWorks page for trim and margins. The Pages view is another view of the manuscript at that trim — not a second dialect. Flow breaks stay hard breaks into Docx and the print-proof PDF.
