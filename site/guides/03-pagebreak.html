3 Getting started

Mark the page break

Print needs a mark in the file. Write the turn where the page must start.

Default break

Use \newpage (blank lines around it) or the authoring form //---. Both mean: start the next flow unit — a page when you are not in columns. 

The gate was never gospel.

//---

# After the break

What is not a page break

  • --- is a scene pause (thematic break), not a page turn
  • A # heading alone does not start a print chapter page
  • CSS tricks in an HTML preview are not the manuscript contract

Authoring tip

Keep //--- on its own line. The writer should leave it visible in the file so export and verify see the same mark you wrote.
