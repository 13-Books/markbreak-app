Getting started

Four short steps from a blank page to a gated print manuscript.

1

Open the writer

Start online, or open a local Markdown / CSV file.

 2

Set the role

Name the print matter in YAML — chapter, epilog, and friends.

 3

Mark the page break

Write the turn into the file with //break. Use //break page to force a page.

 4

Export & verify

Ship through Pandoc. Fail the build when the break is missing.
