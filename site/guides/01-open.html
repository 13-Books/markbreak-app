1 Getting started

Open the writer

Start drafting in the browser. No account. Your file stays yours.

Online

Open the online editor. Paste a draft, or load a remote file with a query: 

edit.html?url=https://markbreak.com/SPEC.md

Short scratch text works too: edit.html?text=%23%20Hello. Spreadsheets open the same way — try demo.csv.

Desktop

The MarkBreak desktop app is the same dialect in a window — open a folder of chapters, keep writing offline, export when ready.

What you should see

  • A writing surface that renders Markdown as you type
  • A way to open a URL, a local file, or share a link back out
  • A path to the open profile on markbreak.com
