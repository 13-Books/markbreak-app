# Focus-writer sketch (archive)

This folder is an archived sketch. It shows pages correctly — trim, margins, folio numbers, and spread pairing (page 1 on the recto) — and that visual correctness is useful as a reference.

It is **not** a golden example, not a product specification, and not shipped chrome. The product Pages/Spreads view is built fresh in the desktop app as another view of the one manuscript. Do not port this sketch's editing model, contenteditable trees, or chrome.

Fonts under `fonts/` are OFL 1.1 and may be bundled into the desktop app with their licence texts.
